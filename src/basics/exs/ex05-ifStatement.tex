\section*{القسم الأوّل: جملة الشرط البسيطة}

\begin{enumerate}[itemsep=2em]

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا (غير الصفر)، ويطبع له "\textbf{موجب}" إذا كان العدد أكبر من صفر، و"\textbf{سالب}" إذا كان أصغر من صفر.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter an integer:");
int num = int.Parse(Console.ReadLine());
if (num > 0)
{
    Console.WriteLine("Positive");
}
else
{
    Console.WriteLine("Negative");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا موجبًا، ويطبع له "\textbf{زوجي}" إذا كان العدد زوجيًا، و"\textbf{فردي}" إذا كان فرديًا.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter a positive integer:");
int num = int.Parse(Console.ReadLine());
if (num % 2 == 0)
{
    Console.WriteLine("Even");
}
else
{
    Console.WriteLine("Odd");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم علامة طالب (عدد صحيح بين 0 و 100)، ويطبع له "\textbf{ناجح}" إذا كانت العلامة 55 فما فوق، و"\textbf{راسب}" إذا كانت أقل من 55.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter student grade:");
int grade = int.Parse(Console.ReadLine());
if (grade >= 55)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Failed");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم كلمة مرور (\textenglish{string})، فإذا كانت الكلمة تطابق \textenglish{"open123"} يطبع له "\textbf{أهلاً بك}"، وإلا يطبع له "\textbf{كلمة المرور خاطئة}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter password:");
string password = Console.ReadLine();
if (password == "open123")
{
    Console.WriteLine("Welcome");
}
else
{
    Console.WriteLine("Wrong password");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم حرفًا واحدًا (\textenglish{char}) يمثل جنس المشترك (\textenglish{'M'} للذكر أو \textenglish{'F'} للأنثى). إذا أدخل المستخدم \textenglish{'M'} يطبع له "\textbf{ذكر}"، وإلا يطبع له "\textbf{أنثى}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter gender (M/F):");
char gender = char.Parse(Console.ReadLine());
if (gender == 'M')
{
    Console.WriteLine("Male");
}
else
{
    Console.WriteLine("Female");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم رقمين مختلفين، ويطبع له "\textbf{الرقم الأول أكبر}" إذا كان الرقم الأول أكبر من الثاني، و"\textbf{الرقم الثاني أكبر}" إذا كان الرقم الثاني أكبر من الأول.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first number:");
int num1 = int.Parse(Console.ReadLine());
Console.WriteLine("Enter second number:");
int num2 = int.Parse(Console.ReadLine());
if (num1 > num2)
{
    Console.WriteLine("The first number is larger");
}
else
{
    Console.WriteLine("The second number is larger");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم رقمين، ويطبع له "\textbf{لهما نفس الإشارة}" إذا كان كلاهما موجبَين أو كلاهما سالبين، و"\textbf{إشارتان مختلفتان}" إذا كان أحدهما موجبًا والآخر سالبًا. \\
(افترض أنّ الرقمين ليسا صفرًا.)
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first number:");
int num1 = int.Parse(Console.ReadLine());
Console.WriteLine("Enter second number:");
int num2 = int.Parse(Console.ReadLine());

int product = num1 * num2;
if (product > 0)
{
    Console.WriteLine("Same sign");
}
else
{
    Console.WriteLine("Different signs");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم سلسلتين نصيتين (\textenglish{string})، ويفحص هل هما متطابقتان تمامًا. إذا كانتا متطابقتين يطبع "\textbf{النصان متطابقان}"، وإلا يطبع "\textbf{النصان مختلفان}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first text:");
string text1 = Console.ReadLine();
Console.WriteLine("Enter second text:");
string text2 = Console.ReadLine();
if (text1 == text2)
{
    Console.WriteLine("Identical strings");
}
else
{
    Console.WriteLine("Different strings");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\end{enumerate}

\section*{القسم الثاني: جملة الشرط المنفردة بدون \textenglish{else}}

\begin{enumerate}[resume, itemsep=2em]

\item
اكتب برنامجًا يستقبل من المستخدم درجة حرارة، ويطبع له "\textbf{الجو حار}" إذا كانت درجة الحرارة أكثر من 30 درجة.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter temperature:");
int temperature = int.Parse(Console.ReadLine());
if (temperature > 30)
{
    Console.WriteLine("It's hot");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم رقمًا، ويطبع له "\textbf{الرقم ليس صفر}" إذا كان الرقم لا يساوي صفرًا.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter a number:");
int number = int.Parse(Console.ReadLine());
if (number != 0)
{
    Console.WriteLine("The number is not zero");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم رقمين، ويطبع له "\textbf{الرقمان غير متساويين}" إذا كان الرقم الأول لا يساوي الثاني.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first number:");
int num1 = int.Parse(Console.ReadLine());
Console.WriteLine("Enter second number:");
int num2 = int.Parse(Console.ReadLine());
if (num1 != num2)
{
    Console.WriteLine("The numbers are not equal");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم سعر مشتريات (عدد عشري). إذا كان السعر أكبر من 200 شيكل، يحصل المشتري على خصم بقيمة 30 شيكل (تطرح 30 من السعر). وفي نهاية البرنامج (في جميع الحالات) يطبع البرنامج السعر النهائي للدفع، متبوعًا بعبارة: "\textbf{شكرًا لتسوقكم}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter purchase price:");
double price = double.Parse(Console.ReadLine());
if (price > 200)
{
    price = price - 30;
}
Console.WriteLine("Final price: " + price);
Console.WriteLine("Thank you for shopping");
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم الرصيد البنكي الحالي (عدد صحيح) والمبلغ المراد سحبه. البرنامج يقوم بطرح المبلغ المسحوب من الرصيد. إذا أصبح الرصيد سالبًا (أقل من صفر)، يطبع البرنامج رسالة تنبيه: "\textbf{تنبيه: دخلت في السحب الزائد}". وفي نهاية البرنامج (في جميع الحالات) يطبع البرنامج الرصيد المتبقي.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter balance:");
int balance = int.Parse(Console.ReadLine());
Console.WriteLine("Enter withdrawal amount:");
int withdraw = int.Parse(Console.ReadLine());
balance = balance - withdraw;
if (balance < 0)
{
    Console.WriteLine("Warning: Overdraft!");
}
Console.WriteLine("Remaining balance: " + balance);
\end{minted}
\end{english}
\end{boxSolution}
\fi

\end{enumerate}

\clearpage

\section*{القسم الثالث: الشروط المتعددة (\textenglish{if - else if - else})}

\begin{enumerate}[resume, itemsep=2em]

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا، ويطبع له رسالة توضح طبيعة العدد:
\begin{itemize}
\item "\textbf{موجب}" إذا كان العدد أكبر من صفر.
\item "\textbf{سالب}" إذا كان العدد أصغر من صفر.
\item "\textbf{صفر}" إذا كان العدد يساوي صفرًا.
\end{itemize}
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter an integer:");
int num = int.Parse(Console.ReadLine());
if (num > 0)
{
    Console.WriteLine("Positive");
}
else if (num < 0)
{
    Console.WriteLine("Negative");
}
else
{
    Console.WriteLine("Zero");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا موجبًا، ويطبع له رسالة مناسبة عن العدد: هل الرقم مكون من منزلة، أو منزلتين، أو أكثر.
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter number:");
int num = int.Parse(Console.ReadLine());
if (num < 10)
{
    Console.WriteLine("The number is made of one digit");
}
else if (num < 100)
{
    Console.WriteLine("The number is made of 2 digits");
}
else
{
    Console.WriteLine("The number is made of more than 2 digits");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\ifwhiteblack
    \clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عمر إنسان (بالسنوات)، ويطبع تصنيف المرحلة العمرية المناسبة:
\begin{itemize}
\item "\textbf{طفل}" إذا كان العمر أقل من 13 سنة.
\item "\textbf{مراهق}" إذا كان العمر بين 13 و 19 سنة.
\item "\textbf{بالغ}" إذا كان العمر 20 سنة أو أكثر.
\end{itemize}
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter age:");
int age = int.Parse(Console.ReadLine());
if (age < 13)
{
    Console.WriteLine("Child");
}
else if (age <= 19)
{
    Console.WriteLine("Teenager");
}
else
{
    Console.WriteLine("Adult");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عددين، ويطبع رسالة مناسبة مقارنةً بينهما:
\begin{itemize}
\item "\textbf{الرقم الأول أكبر}" إذا كان الأول أكبر من الثاني.
\item "\textbf{الرقم الثاني أكبر}" إذا كان الثاني أكبر من الأول.
\item "\textbf{الرقمان متساويان}" إذا كان الرقمان متساويين.
\end{itemize}
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first number:");
int a = int.Parse(Console.ReadLine());
Console.WriteLine("Enter second number:");
int b = int.Parse(Console.ReadLine());
if (a > b)
{
    Console.WriteLine("The first number is larger");
}
else if (b > a)
{
    Console.WriteLine("The second number is larger");
}
else
{
    Console.WriteLine("The numbers are equal");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi
\clearpage

\item
اكتب برنامجًا يستقبل من المستخدم علامة طالب، ويطبع له التقدير المناسب حسب العلامة:
\begin{itemize}
\item \texttt{A+} إذا كانت العلامة 95 أو أكثر
\item \texttt{A} إذا كانت العلامة 90-94
\item \texttt{A-} إذا كانت العلامة 85-89
\item \texttt{B+} إذا كانت العلامة 80-84
\item \texttt{B} إذا كانت العلامة 75-79
\item \texttt{B-} إذا كانت العلامة 70-74
\item \texttt{C} إذا كانت العلامة أقل من 70
\end{itemize}
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter your grade:");
int grade = int.Parse(Console.ReadLine());
if (grade >= 95)
{
    Console.WriteLine("A+");
}
else if (grade >= 90)
{
    Console.WriteLine("A");
}
else if (grade >= 85)
{
    Console.WriteLine("A-");
}
else if (grade >= 80)
{
    Console.WriteLine("B+");
}
else if (grade >= 75)
{
    Console.WriteLine("B");
}
else if (grade >= 70)
{
    Console.WriteLine("B-");
}
else
{
    Console.WriteLine("C");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\end{enumerate}

% القسم الرابع: الشروط المركبة (&&, ||, !)

\section*{القسم الرابع: الشروط المركبة}

\begin{enumerate}[resume, itemsep=2em]

\item
اكتب برنامجًا يستقبل من المستخدم رقمين، ويطبع له "\textbf{الرقمان موجبان}" إذا كان كلاهما أكبر من صفر، وإلا يطبع "\textbf{ليس كلاهما موجبين}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter first number:");
int num1 = int.Parse(Console.ReadLine());
Console.WriteLine("Enter second number:");
int num2 = int.Parse(Console.ReadLine());
if (num1 > 0 && num2 > 0)
{
    Console.WriteLine("Both numbers are positive");
}
else
{
    Console.WriteLine("Not both are positive");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم درجة حرارة، ويطبع له "\textbf{الجو غير مناسب}" إذا كانت درجة الحرارة أقل من 10 أو أكثر من 40، وإلا يطبع "\textbf{الجو مناسب}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter temperature:");
int temperature = int.Parse(Console.ReadLine());
if (temperature < 10 || temperature > 40)
{
    Console.WriteLine("Weather is not suitable");
}
else
{
    Console.WriteLine("Weather is suitable");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عمر شخص ودرجة حرارة، ويطبع له "\textbf{يمكنك الخروج}" إذا كان عمره 18 أو أكثر ودرجة الحرارة أقل من 35، وإلا يطبع "\textbf{لا يمكنك الخروج}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter your age:");
int age = int.Parse(Console.ReadLine());
Console.WriteLine("Enter temperature:");
int temperature = int.Parse(Console.ReadLine());
if (age >= 18 && temperature < 35)
{
    Console.WriteLine("You can go out");
}
else
{
    Console.WriteLine("You cannot go out");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا موجبًا، ويطبع له "\textbf{عدد ثنائي المنازل}" إذا كان العدد مكونًا من منزلتين (أي يقع بين 10 و 99 مشمولاً)، وإلا يطبع "\textbf{ليس ثنائي المنازل}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter a positive number:");
int num = int.Parse(Console.ReadLine());
if (num >= 10 && num <= 99)
{
    Console.WriteLine("Two-digit number");
}
else
{
    Console.WriteLine("Not a two-digit number");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi
\clearpage

\item
اكتب برنامجًا يستقبل من المستخدم عددًا صحيحًا، ويطبع له "\textbf{يقبل القسمة على 2 و 3 معًا}" إذا كان يقبل القسمة على 2 و 3 بدون باقٍ، وإلا يطبع "\textbf{لا يقبل القسمة على كليهما}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter an integer:");
int num = int.Parse(Console.ReadLine());
if (num % 2 == 0 && num % 3 == 0)
{
    Console.WriteLine("Divisible by 2 and 3");
}
else
{
    Console.WriteLine("Not divisible by both");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم رقم اليوم في الأسبوع (من 1 إلى 7، حيث 1 للأحد، 6 للجمعة، و 7 للسبت). يطبع البرنامج "\textbf{عطلة نهاية الأسبوع}" إذا كان اليوم 6 أو 7، وإلا يطبع "\textbf{يوم دراسة وعمل}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter day number (1-7):");
int day = int.Parse(Console.ReadLine());
if (day == 6 || day == 7)
{
    Console.WriteLine("Weekend");
}
else
{
    Console.WriteLine("Work day");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
اكتب برنامجًا يستقبل من المستخدم نوع اليوم (1 للعمل، 2 للعطلة) ودرجة الحرارة، ويطبع له "\textbf{يوم ممتع}" إذا كان يوم عطلة أو درجة الحرارة بين 20 و 25، وإلا يطبع "\textbf{يوم عادي}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter day type (1=Work, 2=Holiday):");
int dayType = int.Parse(Console.ReadLine());
Console.WriteLine("Enter temperature:");
int temperature = int.Parse(Console.ReadLine());
if (dayType == 2 || (temperature >= 20 && temperature <= 25))
{
    Console.WriteLine("Enjoyable day");
}
else
{
    Console.WriteLine("Regular day");
}
\end{minted}
\end{english}
\end{boxSolution}
\fi

\item
اكتب برنامجًا يستقبل من المستخدم قيمة منطقية (\textenglish{bool}) تحدد هل الطالب معفى من الامتحان (\textenglish{isExempt})، وعلامته في الوظيفة (عدد صحيح). إذا كان الطالب \textbf{غير معفى} وعلامته أقل من 60، يطبع البرنامج "\textbf{عليك التقدم للامتحان}"، وإلا يطبع "\textbf{لا حاجة للتقدم للامتحان}".
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Is exempt? (true/false):");
bool isExempt = bool.Parse(Console.ReadLine());
Console.WriteLine("Enter homework grade:");
int grade = int.Parse(Console.ReadLine());
if (!isExempt && grade < 60)
{
    Console.WriteLine("You must take the exam");
}
else
{
    Console.WriteLine("No need to take the exam");
}
\end{minted}
\end{english}
\end{boxSolution}
\clearpage
\fi

\item
عند حل معادلة تربيعية من الصورة $ax^2 + bx + c = 0$
نرمز لـ $\Delta = b^2 - 4ac$ وعندها:
\begin{itemize}
    \item إذا كان $\Delta < 0$ فعندها لا يوجد حلول حقيقية للمعادلة.
    \item إذا كان $\Delta = 0$ فعندها يوجد حلّ واحد وهو:
    \( x = \frac{-b}{2a} \)
    \item إذا كان $\Delta > 0$ فعندها يوجد حلّان، وهما:
    \[ x_1 = \frac{-b + \sqrt{b^2 - 4ac}}{2a} \qquad x_2 = \frac{-b - \sqrt{b^2 - 4ac}}{2a} \]
\end{itemize}
اكتب برنامجًا يستقبل معاملات المعادلة التربيعية $a,b,c$ ويحسب حلول المعادلة ويطبعها مع رسالة مناسبة.

\begin{boxExample}[2]

\end{boxExample}
\begin{boxExample}[3]
عند استقبال المعاملات: $1, 0, 1$ يطبع: \\ "\textenglish{No solution}"
\end{boxExample}
\fi
\ifwithsols
\begin{boxSolution}
\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter a:");
double a = double.Parse(Console.ReadLine());
Console.WriteLine("Enter b:");
double b = double.Parse(Console.ReadLine());
Console.WriteLine("Enter c:");
double c = double.Parse(Console.ReadLine());

double delta = Math.Pow(b, 2) - 4 * a * c;
if (delta < 0)
{
    Console.WriteLine("No solution");
}
else if (delta == 0)
{
    double x = -b / (2 * a);
    Console.WriteLine("One solution: x = " + x);
}
else
{
    double x1 = (-b + Math.Sqrt(delta)) / (2 * a);
    double x2 = (-b - Math.Sqrt(delta)) / (2 * a);
    Console.WriteLine("Two solutions: x1 = " + x1 + ", x2 = " + x2);
}
\end{minted}
\end{english}
\end{boxSolution}

\item
اكتب برنامجًا يستقبل 3 أعداد صحيحة موجبة تمثل تاريخًا: اليوم (\textenglish{day})، الشهر (\textenglish{month})، والسنة (\textenglish{year}).
يقوم البرنامج بالتحقق من صحة التاريخ:
\begin{itemize}
\item السنة يجب أن تكون موجبة ($year > 0$).
\item الشهر يجب أن يكون بين 1 و 12.
\item اليوم يجب أن يكون صحيحًا وفق أيام كل شهر:
  \begin{itemize}
    \item الأشهر (1, 3, 5, 7, 8, 10, 12): تحتوي على 31 يومًا.
    \item الأشهر (4, 6, 9, 11): تحتوي على 30 يومًا.
    \item شهر شباط (2): يحتوي على 29 يومًا إذا كانت السنة كبيسة، و 28 يومًا إذا كانت سنة عادية.
  \end{itemize}
\end{itemize}
يطبع البرنامج "\textbf{تاريخ صحيح}" إذا كان التاريخ سليمًا، وإلا يطبع "\textbf{تاريخ غير صحيح}".
\ifdetailed
\begin{boxExample}[1]

\begin{minted}{text}
Enter day:
29
Enter month:
2
Enter year:
2024
Valid date
\end{minted}
\end{english}
\end{boxExample}

\begin{minted}{text}
Enter day:
29
Enter month:
2
Enter year:
2023
Invalid date
\end{minted}
\end{english}
\end{boxExample}
\fi

\begin{english}
\begin{minted}{csharp}
Console.WriteLine("Enter day:");
int day = int.Parse(Console.ReadLine());
Console.WriteLine("Enter month:");
int month = int.Parse(Console.ReadLine());
Console.WriteLine("Enter year:");
int year = int.Parse(Console.ReadLine());

bool isValid = false;
if (year > 0 && month >= 1 && month <= 12 && day >= 1)
{
    int maxDays;
    if (month == 1 || month == 3 || month == 5 || month == 7 ||
        month == 8 || month == 10 || month == 12)
    {
        maxDays = 31;
    }
    else if (month == 4 || month == 6 || month == 9 || month == 11)
    {
        maxDays = 30;
    }
    else // Month 2 (February)
    {
        bool isLeap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
        if (isLeap)
        {
            maxDays = 29;
        }
        else
        {
            maxDays = 28;
        }
    }

    if (day <= maxDays)
    {
        isValid = true;
    }
}

if (isValid)
{
    Console.WriteLine("Valid date");
}
else
{
    Console.WriteLine("Invalid date");
}
\end{minted}
\end{english}
