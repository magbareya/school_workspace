\item
أمامك مقطع البرنامج التالي الذي يستقبل عددًا صحيحًا موجبًا $num$ مكوّنًا من $3$ منازل (بين $100$ و $999$):

\begin{boxCode}
\begin{english}
\begin{minted}{csharp}
int num = int.Parse(Console.ReadLine());
int a = num / 100;
int b = (num / 10) % 10;
int c = num % 10;
int m = Math.Max(a, c);
int d = Math.Abs(a - b);
int res = m * 10 + d;
Console.WriteLine(res);
\end{minted}
\end{english}
\end{boxCode}

    \item لطباعة $75$ مع $a < b$: يجب أن يكون $m = 7$ و $b - a = 5$، مثل: $num = 277$ (أو $387$ أو $497$).
\end{itemize}

int a = int.Parse(Console.ReadLine());
int b = int.Parse(Console.ReadLine());
int min = Math.Min(a, b);
int max = Math.Max(a, b);

if (min <= 0)
{
    if (max > 0 && Math.Abs(min) > max)
    {
        Console.WriteLine("A");
    }
    else
    {
        Console.WriteLine("B");
    }
}
else
{
    if (max % min == 0 && a != b)
    {
        Console.WriteLine("C");
    }
    else
    {
        Console.WriteLine("D");
    }
}
\end{minted}
\end{english}
\end{boxCode}
