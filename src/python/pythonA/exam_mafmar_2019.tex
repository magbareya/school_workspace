\item ($15$ علامة) أمامك ثلاثة مقاطع برنامج تتضمّن عملية باسم \textenglish{num\_even}.
الهدف من كل واحد من مقاطع البرنامج هو استقبال $10$ أعداد صحيحة، وطباعة كمية الأعداد \textbf{ثنائية المنازل الموجبة} (من $10$ إلى $99$) التي ظهرت في المُدخل.
\textbf{مثال:} لسلسلة الأعداد العشرة التالية: $230$، $-555$، $76$، $5$، $80$، $-100$، $77$، $8$، $74$، $90$، يُطبع العدد $5$.
في كل مقطع برنامج وقع خطأ منطقي واحد، ولذلك لا يحقّق المقطع هدفه. اشرح الخطأ وصحّحه.
(ملاحظة: الخطأ ليس خطأ وقت تشغيل. افترض أنّ المُدخل سليم ويشمل أعدادًا صحيحة فقط.)

\begin{enumerate}[label=\textbf{مقطع \alph*:}, wide=0pt, leftmargin=*, itemsep=1.5em]

\item .
\begin{boxCode}
\begin{english}
\begin{minted}{python}
def num_even():
    count = 0
    index = 0
    num = int(input("Enter an integer number"))
    while index < 10:
        if num <= 99 and num >= 10:
            count = count + 1
        index = index + 1
    print("count", count)
\end{minted}
\end{english}
\end{boxCode}
\ifwithsols
\begin{boxSolution}
\textbf{الخطأ:} أمر الاستقبال \textenglish{\texttt{num = int(input(...))}} مكتوب خارج الحلقة فقط، ولذلك يستقبل البرنامج عددًا واحدًا فقط ويفحصه $10$ مرات بدل استقبال $10$ أعداد مختلفة. \\
\textbf{التصحيح:} نقل (أو إضافة) السطر \textenglish{\texttt{num = int(input("Enter an integer number"))}} إلى داخل حلقة \textenglish{while}.
\end{boxSolution}
\else
\textbf{ما هو الخطأ؟} \underline{\hspace{11cm}} \\
\textbf{كيف يجب تصحيحه؟} \underline{\hspace{10cm}}
\fi
\filbreak
